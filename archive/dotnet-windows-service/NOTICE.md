# Abandoned reference: Windows Service / .NET Framework skeleton

This directory is **not** part of the product. It is preserved only so history
of the original 2018-era repository is not silently deleted.

Abandoned with it:

- .NET Framework 4.6.1 Windows Service (`Service1`)
- rqlite as a decentralized database
- rhinodht for node discovery
- IPFS as a replacement for rqlite/rhinodht
- Windows-only agent-first sequencing

The live product is a native Go console and agent on Windows, Linux, and macOS.
Do not extend this skeleton.
